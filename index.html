Google Sheets Sync
1
Add a Data tab to your spreadsheet
Create a new tab called Data. Add this header row in row 1:

Name | Date | Time | Systolic | Diastolic | Pulse | Arm | Position | Classification | Notes
2
Open Apps Script and paste the receiver
Go to Extensions → Apps Script. Delete all existing code and paste this updated version (it now includes doGet for cross-device sync, plus the original doPost for writing):
// Returns all readings so the app can sync across devices function doGet(e) { try { var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Data"); var values = sheet.getDataRange().getValues(); if (values.length <= 1) { return ContentService.createTextOutput(JSON.stringify({ ok:true, readings:[] })) .setMimeType(ContentService.MimeType.JSON); } var readings = values.slice(1).map(function(row) { var d = row[1], t = row[2]; return { date: (d instanceof Date) ? Utilities.formatDate(d, Session.getScriptTimeZone(), 'dd/MM/yyyy') : String(d), time: (t instanceof Date) ? Utilities.formatDate(t, Session.getScriptTimeZone(), 'HH:mm') : String(t), sys: row[3], dia: row[4], pulse: row[5] || '', arm: row[6] || '', position: row[7] || '', classification: row[8] || '', notes: row[9] || '' }; }).filter(function(r) { return r.sys && r.dia; }); return ContentService.createTextOutput(JSON.stringify({ ok:true, readings:readings })) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({ ok:false, error:err.message })) .setMimeType(ContentService.MimeType.JSON); } } // Receives a new reading from the app and appends it to the sheet function doPost(e) { try { var data = JSON.parse(e.postData.contents); var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Data"); sheet.appendRow([ data.name || '', data.date, data.time, data.sys, data.dia, data.pulse || '', data.arm, data.position, data.classification, data.notes || '' ]); return ContentService.createTextOutput(JSON.stringify({ ok:true })) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({ ok:false, error:err.message })) .setMimeType(ContentService.MimeType.JSON); } }
!
Already deployed? Update your existing deployment
If you deployed the old version: paste the new code above, then go to Deploy → Manage deployments, click the pencil icon on your existing deployment, change Version to "New version", and click Deploy. The URL stays the same — no need to update Settings.

Deploy as a Web App
Deploy → New deployment → Web app

4
Paste into Settings and test
Go to Settings, paste the URL, click Test connection. Delete the test row from your sheet. Done.
You already have a GitHub account — great. This gets you from zero to a live shareable URL in about five minutes. No coding required.
Part 1 — Create a Repository
1
Go to github.com and sign in
Once in, click the + icon in the top-right corner of the page and choose New repository.
2
Name the repository
In the Repository name field, type: bp-tracker

Leave the description blank. Make sure Public is selected (not Private — GitHub Pages only works on public repos for free accounts).

Tick Add a README file. Then click Create repository.
Part 2 — Upload the File
3
Open your new repository
After creating it you'll land on the repository page. You'll see a single file called README.md. That's fine — ignore it for now.
4
Upload bp_tracker.html and rename it
Click Add file → Upload files.

Drag your bp_tracker.html file onto the upload area, or click choose your files to browse to it.

Important: After the upload box shows your file, scroll down to the Commit changes section and click Commit changes. Don't change anything else yet.
5
Rename the file to index.html
Back on your repository page, click on bp_tracker.html to open it.

Click the pencil icon (Edit this file) in the top right of the file view.

At the very top, you'll see the filename in a text box. Change bp_tracker.html to index.html.

Scroll down and click Commit changes.
Part 3 — Enable GitHub Pages
6
Go to repository Settings
On your repository page, click the Settings tab (it has a gear icon). It's in the row of tabs near the top of the page — not the global account settings.
7
Find Pages in the left sidebar
In the left-hand menu, scroll down to Pages (under the "Code and automation" section) and click it.
8
Set the source branch
Under Branch, click the dropdown that says None and select main.

Leave the folder as / (root).

Click Save.
9
Wait about 60 seconds, then visit your URL
GitHub will build the site. After roughly a minute, refresh the Settings → Pages page and you'll see a green banner with your URL:

https://YOURUSERNAME.github.io/bp-tracker

That's it. Share that link with anyone — they open it in any browser, immediately, no download needed.
Part 4 — Updating the App
When I send you an updated version of the file, you don't need to redo any of this. Just upload the new file and rename it — the live URL stays the same.
10
To update: delete the old file, upload the new one
On your repository page, click index.html.
Click the three-dot menu (⋯) in the top right and choose Delete file. Commit the deletion.

Then follow steps 4–5 again to upload and rename the new version. The live URL updates within about 30 seconds.
What about other people's data?
Each person who opens your link gets their own private copy of the app in their own browser. Your data and theirs never mix — there's no server, no database, no accounts. The URL is just a way to deliver the file. Everything else happens locally on their device.
